# 🎓 College Schedule Generator — Генератор расписания колледжа

**College Schedule Generator** — это веб-приложение для автоматического создания и управления расписанием занятий в колледже. Сервис решает реальную проблему: помогает учебной части быстро составлять расписание, учитывая занятость преподавателей, аудиторий и групп.

Проект написан на **Go** с использованием **PostgreSQL**, **Docker** и чистой архитектуры. Включает полноценный фронтенд для удобного взаимодействия.

---

## 🚀 Основные возможности

| Функция | Описание |
|---------|----------|
| 📅 **Генерация расписания** | Автоматическое создание расписания на основе введённых данных |
| 👨‍🏫 **Управление преподавателями** | Добавление, редактирование и удаление преподавателей |
| 🏫 **Управление группами** | Создание групп с указанием специальности и курса |
| 🪑 **Управление аудиториями** | Добавление аудиторий с указанием вместимости и типа |
| ⚡ **Проверка конфликтов** | Автоматическая проверка занятости преподавателей и аудиторий в одно время |
| 🐳 **Контейнеризация** | Лёгкий запуск через Docker и Docker Compose |
| 🗄️ **Надёжное хранение** | PostgreSQL для хранения всех данных |

## 📁 Архитектура проекта

Проект построен на слоёной архитектуре, что обеспечивает разделение ответственности и упрощает масштабирование:
lesson/
├── cmd/ # Точка входа (main.go)
├── internal/ # Внутренние пакеты
│ ├── config/ # Конфигурация приложения
│ ├── handlers/ # HTTP-обработчики (слой представления)
│ ├── models/ # Модели данных
│ ├── repository/ # Слой доступа к данным (PostgreSQL)
│ └── service/ # Бизнес-логика (генерация расписания)
├── pkg/ # Переиспользуемые утилиты
│ └── database/ # Подключение к БД
├── db/migrations/ # SQL-миграции
├── frontend/ # Статические файлы (HTML, CSS, JS)
├── docker-compose.yml # Контейнеризация
├── Dockerfile # Сборка образа
├── Makefile # Команды для разработки
├── .env.example # Пример переменных окружения
└── go.mod # Зависимости Go


## 🔧 Установка и запуск

### Требования
- Go 1.21+
- Docker и Docker Compose

### Запуск через Docker (рекомендуемый способ)

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/KashimooF/lesson.git
   cd lesson

2.Настройте переменные окружения (скопируйте .env.example в .env и измените при необходимости):
cp .env.example .env

3.Запустите контейнеры:
docker-compose up -d --build

4.Откройте в браузере: http://localhost:8080

Ручной запуск (без Docker)
Установите зависимости: go mod download

Настройте базу данных: make migrate-up

Запустите сервер: go run cmd/main.go

Доступные Makefile-команды
Команда	Описание
make run	Запустить Go-сервер локально
make migrate-up	Применить миграции
make migrate-down	Откатить миграции
make docker-up	Запустить всё в Docker
make docker-down	Остановить контейнеры
make build	Собрать бинарник
📡 API-эндпоинты
Метод	Путь	Описание
GET	/api/groups	Получить список групп
POST	/api/groups	Создать новую группу
GET	/api/teachers	Получить список преподавателей
POST	/api/teachers	Добавить преподавателя
GET	/api/classrooms	Получить список аудиторий
POST	/api/classrooms	Добавить аудиторию
POST	/api/schedule/generate	Сгенерировать расписание
GET	/api/schedule	Получить текущее расписание
🧪 Как я работал над проектом
Этот проект я разрабатывал с нуля, чтобы решить реальную задачу — помочь колледжу автоматизировать создание расписания. В процессе работы я:

Спроектировал архитектуру, разделив приложение на слои (handlers, services, repositories) для чистоты кода.

Разработал схему базы данных в PostgreSQL с учётом связей между группами, преподавателями, аудиториями и предметами.

Реализовал бизнес-логику для автоматической генерации расписания с проверкой конфликтов (преподаватель и аудитория не могут быть заняты одновременно).

Написал миграции для управления схемой БД.

Упаковал приложение в Docker и настроил docker-compose для простого запуска.

Сделал полноценный фронтенд, чтобы пользователи могли взаимодействовать с системой через браузер.
